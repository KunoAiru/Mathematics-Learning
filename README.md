# 数理道場

確率論・統計学・線形代数・抽象代数学・凸解析/最適化と、C++/Rust を**毎日5分**で積み上げる個人用の学習アプリ（PWA）です。スマホのホーム画面に追加して使います。

## 毎日の流れ

1. **復習**: 忘れかけたカードだけが出ます（FSRS アルゴリズムで次の出題日を計算）
2. **新しい概念を1つ**: 定義や定理を読み、手書きメモに書き写してから確認問題へ
3. **今日の1問**: 数学の計算問題とコードの問題が日替わり。計算問題は毎回数値が変わります

3つを最後までやり終えるとその日は「達成」です。途中でやめても、次に開くと続きから再開できます。週に1日までは休んでも連続日数は途切れません。

## カードの種類

| 種類 | 内容 |
|---|---|
| 想起 | 定義・定理の主張を自分で書いてから答えを見る |
| 証明の並べ替え | ばらばらにした証明のステップを正しい順に並べる |
| 確認問題 | 「仮定を外すと？（反例）」「逆は成り立つ？」など |
| 計算問題 | 行列・固有値・確率・剰余演算・勾配など。答えを入力して自動採点 |
| コード | C++ の未定義動作、Rust の所有権・借用などを読んで答える |
| 実装演習 | ガウスの消去法、繰り返し二乗法などを実装する（Compiler Explorer / Rust Playground で開ける） |

ほかに、**知識マップ**（前提関係と習熟度）、**手書きノート**（ペン圧対応、Apple Pencil のペンのみモードあり）、**誤り報告**、**バックアップ**の機能があります。

## 教材の正しさ

`npm run validate -- --code` で次のことを確認しています（CI でも実行）。

- 項目の構造、前提関係の存在と循環の有無
- すべての数式が KaTeX で描画できること
- 計算問題のジェネレーター15種それぞれで300問を作り、別の方法で答えを計算し直して一致すること
- コード問題の主張（コンパイルエラーになる、出力が 0 になる、パニックするなど）を g++/rustc で実際に確かめること
- 実装演習の模範解答がコンパイルでき、テストに通ること

証明の文章などは機械では検証しきれないので、気づいた誤りはアプリの ⚑ ボタンで報告してください。設定画面の「まとめてコピー」で Claude Code に渡せば修正できます。

## 教科書（すべて無料公開）

- 線形代数: Axler, *Linear Algebra Done Right* 4th ed.
- 確率論: Grinstead & Snell, *Introduction to Probability*
- 統計学: *OpenIntro Statistics* 4th ed.
- 抽象代数学: Judson, *Abstract Algebra: Theory and Applications*
- 凸解析・最適化: Boyd & Vandenberghe, *Convex Optimization*
- C++: cppreference.com / learncpp.com
- Rust: *The Rust Programming Language*

## 開発

```sh
npm install
npm run dev                  # 開発サーバー（--host 付きなので同じ Wi-Fi のスマホから開ける）
npm run validate -- --code   # 教材の検証
npm test
npm run build
```

教材は `content/<科目>/*.yaml` にあります。書き方の約束は [CLAUDE.md](./CLAUDE.md) を参照してください。

## 公開（GitHub Pages）

1. リポジトリの Settings → Pages → Build and deployment の Source を **GitHub Actions** にする
2. デフォルトブランチに push すると、検証・テスト・ビルドを通ったものが自動で公開される
3. スマホで公開 URL を開き、ホーム画面に追加する（iPhone は Safari の共有ボタン →「ホーム画面に追加」）

学習記録と手書きメモはスマホの中だけに保存されます。ときどき設定画面からバックアップを書き出してください。
